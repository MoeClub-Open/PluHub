# 适用范围

PluHub 当前为 Alpha，正式运行目标是 Linux x64、Bun 1.4.3。默认单节点，各业务插件维护自己的 SQLite 数据库，部分限流、并发和输出节拍状态保存在进程内存。

新站预装 35 个官方插件，默认启用 18 个基础插件；计费、支付、个人渠道、订阅上游、自动路由、邮件、验证码等按需启用。完整功能入口见 [文档目录](README.md)，插件职责见 [架构说明](PLUGIN_ARCHITECTURE.md)。

## 生产使用边界

| 能力       | 当前支持                                               | 尚需补齐                                         |
| ---------- | ------------------------------------------------------ | ------------------------------------------------ |
| 渠道可靠性 | 模型匹配、会话亲和、订阅账号冷却、个人流程显式备用出口 | 普通平台渠道的通用健康探测、熔断和跨渠道自动切换 |
| 消费预算   | 余额预扣、输出预算、请求频率限制                       | 用户/密钥/项目的日月金额预算和绝对单请求金额上限 |
| 监测与告警 | 请求记录、运行日志、磁盘和插件状态                     | 标准指标导出、跨服务追踪、告警与通知闭环         |
| 商品权益   | 商品、订单、周期余额发放和分组授权                     | 根据订阅自动授予或回收使用分组                   |
| 团队权限   | 管理员/用户、组织归属和日志可见范围                    | 细分管理角色、团队预算和企业统一登录             |
| 成本核算   | 钱包账本、请求估价、退款及争议调整                     | 提供商账单导入、上游成本对账和利润核算           |
| 备份保障   | 本地加密备份、独立恢复检查及固定发布组合               | 异地副本、备份告警和部署环境的恢复保障           |
| 多节点     | 单节点数据库及部分持久账号状态                         | 共享限流/租约、配置分发、数据库高可用和调度      |
| 插件隔离   | 可信代码的权限与依赖检查                               | 不可信后端或前端插件的安全沙箱                   |

不能通过增加共享同一数据卷的副本实现高可用。Native、Process 和前端插件均为安装者授权的本机代码，进程插件不等于沙箱。

## 验证范围

健康探针只说明本地服务可接收请求；模拟测试或单一提供商成功不能证明其他模型、支付、邮件和生产并发可用。协议能力以 [支持矩阵](PROTOCOLS.md) 为准，真实服务须按 [联调说明](LIVE_TESTING.md) 单独验证。

生产前应配置 HTTPS、可信代理和数据备份，按 [运维指南](OPERATIONS.md) 核对恢复流程。发布组合和检查项见 [持续集成](CICD.md)。
