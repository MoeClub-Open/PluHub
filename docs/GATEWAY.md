# AI 网关使用

网页使用流程：登录账号 → 在模型目录选择可用模型 → Playground 流式调用 → 查看请求记录与总览。接入外部客户端时创建个人 API Key。

## 功能入口

| 页面            | 功能                                                                                 | 可访问用户                                                 |
| --------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| 总览            | 24 小时 / 7 天 / 30 天调用量、Token、首 Token 延迟、成本估算、模型排行               | 管理员查看全局；普通用户查看自己                           |
| 模型目录        | 搜索、供应商筛选、价格排序、接入示例、跳转试用                                       | 登录用户；API Key 查询仅返回允许的模型                     |
| Playground      | 对话、图片与视频试用；参数与请求 JSON 编辑、结果预览与下载 | 使用当前登录会话，无需填写 API Key；计入当前账号用量与费用 |
| 调用记录        | 模型、状态及时间筛选、分页、请求 ID、延迟、用量、错误代码                            | 管理员查看全局；普通用户查看自己                           |
| API 密钥        | 创建、复制、轮换、撤销、使用分组或个人渠道、模型范围、有效期、每分钟请求上限         | 本人控制台会话                                             |
| 渠道与路由      | 渠道及模型的表单增删改、启停、模型展示信息、配置价格、显式请求测试、可选 JSON 编辑   | 管理员会话                                                 |
| 用户 / 插件管理 | 用户管理、安装及启停插件                                                             | 管理员会话                                                 |

界面支持明暗主题、键盘焦点、统一模态对话框和移动端侧栏。所有统计来自实际经过网关的请求；没有请求时展示空状态。

全站用户安全、Key 撤销、个人渠道封禁、订单订阅、资金账本和管理操作记录的操作及权限边界见 [管理功能](ADMINISTRATION.md)。

管理员的「系统设置」提供分类总览和设置搜索，进入后侧栏切换为配置导航，可随时返回控制台。「渠道与路由 → 使用分组」独立管理分组、倍率和访问用户。渠道执行功能统一在流程图内配置，限流、TPS 和自动路由不单独占用页面或页签；全局限制从请求入口节点打开，共享策略从自动路由节点打开。「支付与商业」包含支付方式、商品订阅和计费设置；余额调整及用户权限组在用户管理中。Stripe、易支付及后续适配器在「支付方式」页内搜索和配置，适配器停止后从列表移除。「安全与验证」通过一个「登录与验证」入口管理登录注册、邮件、人机验证和 Passkey 策略。插件管理与系统状态有固定管理员入口。

控制台将工具与账号分组。钱包只占一个侧栏入口，页内切换余额账单、充值订阅；订单和订阅分别按需查看。支付选择只显示实际启用的方式，并按商品币种筛选；确认购买后才创建订单，未支付订单可继续付款。取消续订前说明本期权益结束时间，服务端重复取消不重复调用支付平台。管理员余额调整和费用核对输入 USD，精确转换为整数微美元，后台 API 和账本单位保持不变。账号设置通过底部账号入口进入，原有页面地址继续可用。

渠道列表可按名称、ID、地址及已映射模型搜索，组合状态与协议筛选，并按 10/20/50 条分页。选择可跨页和筛选保留，批量操作会显示不在当前页的选中数量；批量停用需要确认影响范围。启停只调整所选渠道，不改变模型映射的独立启停状态，也不触发上游测试。仅当渠道凭证发生变化时才同步相关适配器的密钥引用，保留手动授权和其他插件配置。

## 站点品牌与外观

管理员进入「系统设置 → 站点与品牌 → 品牌与外观」，配置站点名称、简介、Logo、浏览器图标、主题色、登录标题/说明、页脚文案、官网/服务条款/隐私链接和支持邮箱。表单提供实时预览、放弃草稿和保存状态；未保存时刷新或关闭页面会触发浏览器提示。Logo 和图标可上传不超过 64 KiB 的 PNG/JPEG/WebP，或填写 HTTPS / 站内绝对路径；不支持 SVG、任意 HTML、脚本 URL 和含凭证的 URL。链接指向已有页面，不生成政策正文。

配置保存在 `official.console` 的 `config.branding`，通过已有 `http.route` 授权提供公开的 `GET /console/branding`。只有声明的品牌字段会公开；管理写入仍走受管理员保护的配置 API。Console 使用配置快照热更新，不增加安装权限，重启后保留。服务端 HTML 和初始化 JSON 均转义；主题色自动调整明暗主题中的文字及按钮对比度。

```json
{
  "branding": {
    "name": "我的 AI 网关",
    "description": "一个入口，连接所有模型。",
    "accentColor": "#635bff",
    "logoUrl": "https://example.com/logo.png",
    "faviconUrl": "https://example.com/icon.png",
    "loginTitle": "连接所有模型，\n从这里开始。",
    "supportEmail": "support@example.com"
  }
}
```

品牌配置仅覆盖控制台、登录页和站点页脚；不改动公开模型别名、API 协议、邮件模板或支付商托管页面。顶部搜索与 `Ctrl/Cmd+K` 支持查找当前用户可访问的页面和设置，不提供用户数据或订单全文搜索。

## 渠道和模型

添加渠道时填写协议、Base URL，并在「调用上游」节点直接填写 API Key；每行一把，留空保留已保存凭据。保存后密钥进入宿主加密存储，配置仅保留凭据编号，并自动更新文本及媒体适配器的读取授权。参数通过请求和配置传递，详见 [凭据与参数](SECRETS.md)。

在渠道内部的「提供模型」配置公开模型名、显示名称、供应商、描述、上下文长度和端点能力，并管理模型启停。需要从上游导入时，明确选择一个「调用上游」节点后获取目录；不同节点的目录分开查询，不合并同名模型或跨节点取最大的上下文长度。获取目录本身不会发布模型，勾选导入后仍可在渠道内调整；新导入模型默认停用。

每个上游节点可配置自己的 `modelMap`，将渠道模型 ID 映射为该节点的实际上游模型 ID。流程决定请求走哪个节点，映射只负责确定发给该节点的模型；不会因为目录里出现模型就自动选择上游。显式映射中不存在该模型时，在派发前报错，不把公开别名直接发给错误的上游。

渠道外部的「模型定价」只列出已经配置的提供模型，用于修改输入/输出、缓存、按次、阶梯或表达式价格，不再获取上游目录、新增模型、修改模型能力或改变映射。渠道列表中的定价入口会筛选当前渠道。模型定义与价格仍保存在同一条稳定的模型记录中，两个入口各自编辑所属字段；导入同名模型到另一个节点、调整映射或重新读取目录不会覆盖已有价格。

“发送测试请求”使用该渠道的第一个已配置模型，发送 `Reply OK`、默认 256 个输出 Token 预算的非流式请求，超时 30 秒。API 可通过 `maxTokens` 指定 32–1024 的预算。必须收到非空正文和正常结束才通过，空回答和预算截断不会报成功。测试可能产生用量，不会自动周期执行；结果是当次测试结果，不代表持续健康状态。虚拟渠道通过工作流预览或公开模型完整调用验证。

## 密钥与观测语义

- 模型限制使用公开模型 ID 的精确匹配，空列表表示全部模型。过期、撤销及用户禁用会影响后续认证。
- 每分钟上限由请求限流插件按单个密钥、单节点、自然分钟计数，与全局密钥上限取较小值，重启清零；它不是用户总配额或财务预算。
- API Key 用于模型调用，不继承管理员系统权限，也不能创建新 Key 或修改密码。凭证管理必须使用登录会话。
- Observability 将请求元数据写入独立 SQLite，默认保留 30 天，可通过 `retentionDays` 配置为 1–365 天。默认不保存提示词、回答正文和认证头。
- 外部请求及其流程内部的模型调用分别记录；主列表和成功率按外部请求统计，成功、失败和客户端取消分开计算。成功率为成功数 /（成功数 + 失败数），取消不计入失败。
- 延迟分为总耗时与首次文本/工具输出时间；Playground 展示的是浏览器观察到的首字延迟，两者测量位置不同。
- 上游未返回有效用量时记录未知；未配置输入/输出价格或缺少用量时不计算成本。成本按请求开始时绑定的价格快照估算，不用于钱包扣费、结算或可靠财务记账。
- 流式响应中途失败时，HTTP 可能已返回 200，需查看最终状态及错误代码。返回头 `x-pluhub-request-id` 可用于定位日志，包括非流式错误响应。

## 本地演示

```sh
pnpm bootstrap
pnpm build:all
pnpm demo
```

访问 `http://127.0.0.1:18181`，使用终端输出的 `admin` 密码。演示上游运行于本机 `18182`，使用固定演示文本和用量，不调用付费接口；配置、数据库与正式配置隔离。可设置 `PLUHUB_DEMO_PASSWORD`、`PLUHUB_DEMO_PORT` 和 `PLUHUB_DEMO_UPSTREAM_PORT`。每次启动会重置演示路由与管理员密码，数据库保留。

正式运行仍使用 README 的 `init / bootstrap-admin / start` 流程。

## 从上一版配置升级

停止宿主，先备份配置及数据目录。Auth 的 SQLite v1 数据会自动迁移并保留已有密码、会话及 Key；已有 Key 默认无模型及频率限制、不过期，但不再具有管理员管理权限。

在 Auth 的配置条目 `grants` 中增加 `hooks.register`。另外安装 `model-catalog`、`observability`、`playground`、`leaderboard`，分别授权其 Manifest 声明的权限。新的 `init` 预装全部 35 个插件。容器在启动锁内执行现行离线迁移；源码升级使用 [运维指南](OPERATIONS.md) 中的迁移入口，不在在线业务逻辑中保留旧授权模式。

## 模型试用

侧栏「模型试用」进入 Playground，切换「对话」「图片」「视频」。模型目录的「使用」会按模型端点进入相应模式，并保留渠道与使用分组。模型列表来自本人权限内的目录，图片与视频仅显示声明了对应端点的模型，不根据名字猜测能力。

图片和视频采用参数 / 请求 JSON、预览 / 响应 JSON 的双栏工作区，窄屏上下排列。参数和 JSON 可以切换编辑；实际模型、渠道和分组仍由当前选择确定。未填写的尺寸、质量、格式及时长交给上游默认处理。生成结果可直接预览、下载或打开，调用记录链接用于核对错误与费用。当前浏览器会话按账号分别保存各模式的文字草稿，附件和生成结果不写入浏览器持久存储。

图片模式支持文生图；选择参考图片后调用图片编辑端点，所选模型须声明 `images/edits`。视频模式支持文本及可选的单张参考图片，生成完成后播放结果。生成期间不能切换模式或修改参数；「停止等待」会断开本次连接，但不承诺撤销提供商已经接受的任务。结果不明时保留资金预留，按调用记录核对，不能把停止等待当作退款。

交互参考 EasyJev 的双栏请求编辑和结果视图，使用本站现有组件与网关实现，不依赖其 TypeSafe Jev 专用接口。图片、视频的协议、定价和上游配置见 [协议说明](PROTOCOLS.md#图片视频向量与音频)。

### 对话

「对话设置」选择思考强度；模型声明支持范围时仅展示该范围，未声明时提供低、中、高和模型默认。默认不强制发送 Temperature 或输出上限，实际预算仍由网关计费策略和提供商能力决定。回答支持 Markdown 标题、列表、表格、代码复制，以及 `$...$` / `$$...$$`、`\(...\)` / `\[...\]` 公式。`mermaid` 代码块在生成结束后渲染为流程图、时序图或图表，语法无效时保留源码。原始 HTML 不执行，数学渲染不信任命令，图表使用严格模式。

Enter 发送，Shift+Enter 换行。生成时可继续编写下一条消息，并可停止当前生成。向上阅读时新内容不会强制滚动；「回到最新」恢复跟随。对话设置和当前会话按账号保存在当前浏览器会话，回答、代码和来源可以分别查看或复制。

取消和中断的请求也会结算，有有效用量时按用量收费，否则按预扣金额收费；调用详情展示结算依据及实际扣费，TPS 按输出 Token 数除以总耗时计算。资金说明见 [计价](PRICING.md)。
