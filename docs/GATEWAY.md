# AI 网关使用

部署并完成 [首次设置](PORTAL.md) 后，管理员配置渠道及提供模型，用户从模型目录、在线试用或外部客户端发起调用。

## 配置渠道和模型

在后台「渠道与路由」创建渠道，进入流程图，在「调用上游」节点配置协议、Base URL 和 API Key。每行可填写一把密钥，留空保留已保存凭据；保存后加密存储，适配器读取授权自动同步。存储与备份规则见 [凭据存储](SECRETS.md)。

在渠道的「提供模型」管理公开模型名、显示名称、供应商、介绍、上下文长度、接口能力、启停和各上游目标。订阅渠道从该节点所选账号的目录选择目标；普通 API 渠道可填写实际模型 ID。

导入目录时先选择上游节点，各节点分别查询。导入的模型默认停用，不覆盖已有价格；同名不代表能力相同，应填写各节点共同支持的能力。请求入口连接多个上游后按模型匹配，同模型候选按会话亲和或轮询选择，规则见 [多上游与映射](WORKFLOWS.md#多个上游与模型映射)。

外部「模型定价」只编辑已配置模型的价格，不新增模型或修改映射。输入/输出、缓存、按次、阶梯和表达式价格见 [模型计价](PRICING.md)。模型重定向、条件、请求限流和输出速度在 [渠道流程图](WORKFLOWS.md) 设置；跨渠道默认限制在「模型服务 → 全局限制」设置。

保存并启用渠道及模型后，在模型目录查看结果。渠道列表支持名称、ID、地址和模型搜索，状态/协议筛选、分页及跨页批量启停。启停渠道不改变模型自身的启停状态。

「发送测试请求」向第一个已配置模型发送 `Reply OK`，默认输出预算 256 Token、超时 30 秒；API 的 `maxTokens` 可设为 32–1024。非空且正常结束的回答才通过，测试会产生实际用量，也不代表持续健康。尚未保存的图可用路径预览检查，但预览不访问上游。

## 使用分组与调用范围

在「渠道与路由 → 使用分组」配置可用平台渠道、倍率、启停和用户权限。默认分组未指定渠道时覆盖全部平台渠道；其他分组显式选择渠道，指定用户名单为空时没有用户可用。

平台 API Key 绑定一个使用分组，个人 API Key 绑定本人的个人渠道。登录会话未指定分组时使用默认分组。模型目录、费用试算、路由和自动选型共用范围检查；`x-pluhub-channel` 只能选择当前范围内的渠道，不能切换分组或扩大权限。分组停用或无权访问时拒绝调用，不自动换组；改名不影响以 ID 保存的绑定。

平台调用价格为最终模型价格 × 入口渠道倍率 × 分组倍率，请求保留当时的价格快照。个人调用的手续费、平台分组委托和备用切换见 [个人渠道](PERSONAL_CHANNELS.md)。旧密钥的分组迁移见 [运维指南](OPERATIONS.md#升级与离线迁移)。

## 模型可见范围

在渠道内为模型选择「所有人」「已登录用户」「已消费用户」或「已付款用户」。消费是正金额的请求扣款，付款是已确认的付款入账；赠送余额、人工调整和待支付订单不算付款，删除调用日志也不改变账本中的资格。

访客目录按访客身份筛选；登录后的目录、`/v1/models` 和在线试用按当前账号筛选，个人模型按所有权展示。该设置控制列表展示，实际调用仍按原有密钥范围、模型授权及计费规则执行。

## 接入客户端

在「API 密钥」创建密钥，选择使用分组或个人渠道，按需设置模型范围、有效期和每分钟请求上限。API Key 用于模型调用，不能操作账号或管理配置。模型范围为空表示允许当前渠道范围内的所有模型；指定模型时按公开 ID 精确匹配。

将客户端 Base URL 设为站点的 `/v1` 地址，使用网关签发的密钥和目录中的公开模型名：

```sh
curl https://hub.example.com/v1/chat/completions \
  -H 'Authorization: Bearer <网关 API Key>' \
  -H 'Content-Type: application/json' \
  -d '{"model":"my-assistant","messages":[{"role":"user","content":"你好"}]}'
```

服务商密钥只保存在上游节点，与客户端密钥分开。其他入口、工具及媒体接口见 [协议支持矩阵](PROTOCOLS.md)。

## 在线试用

「模型试用」使用当前登录会话，无需再次填写 API Key，产生的用量和费用归当前账号。模型目录中的「使用」会保留模型、渠道和分组，并按接口能力打开对话、图片或视频模式。

### 对话

「对话设置」可选模型支持的思考强度；未声明支持范围时提供低、中、高及模型默认。默认不强制发送 Temperature 或输出上限，预算仍由计费策略和提供商能力决定。

回答支持 Markdown、表格、代码复制、KaTeX 公式和 Mermaid 图表。公式可用 `$...$`、`$$...$$`、`\(...\)` 或 `\[...\]`；Mermaid 在生成结束后渲染，无效语法保留源码。页面不执行回答中的原始 HTML。

Enter 发送，Shift+Enter 换行；生成期间可编写下一条消息或停止生成。向上阅读时不强制滚动，「回到最新」恢复跟随。设置和对话按账号保存在当前浏览器会话。

### 图片和视频

可切换参数表单与请求 JSON，生成后查看预览、响应 JSON 或下载结果。模型、渠道和分组以当前选择为准；未填写的尺寸、质量、格式及时长交给上游默认处理。

图片支持文生图和参考图片编辑，编辑需模型声明 `images/edits`。视频支持文本和可选的一张参考图片，等待完成后播放。生成期间不能修改参数；「停止等待」断开连接，不能撤销提供商已接受的任务，已派发请求按 [结算规则](PRICING.md#取消中断与重启结算) 收费。

各模式文字草稿按账号保存在浏览器会话，附件与生成结果不持久保存。实际支持的端点和上游限制见 [媒体协议](PROTOCOLS.md#图片视频向量与音频)。

## 查看调用

总览展示汇总、趋势和消耗分类；调用记录提供筛选、导出、分页和单次详情。用响应头 `x-pluhub-request-id` 可定位对应记录；流式响应的 HTTP 200 不代表最终成功。

普通用户查看自己的记录，企业主账号可查看直属子账号，管理员可查看全站。记录默认不保存提示词、回答和认证头。耗时、TPS、内部调用及保留策略见 [调用记录与日志](LOGGING.md)，实际扣费以资金账本为准。

站点品牌和公开内容见 [门户设置](PORTAL.md)，账号保护见 [账号安全](IDENTITY.md)，支付和订阅见 [商业功能](COMMERCIAL.md)。
