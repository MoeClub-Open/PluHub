# 界面语言

支持 `zh-CN`（简体中文）和 `en-US`（English）。没有手动选择时，页面按浏览器 `navigator.languages` 的顺序匹配支持的语言；中文地区变体使用简体中文，英语地区变体使用英文。浏览器偏好的语言均不支持时，才使用 `branding.defaultLanguage`，未配置时回退简体中文。首次 HTML 的 `lang` 和门户介绍按请求的 `Accept-Language` 匹配，进入页面后采用当前浏览器或账号选择。

语言菜单与账号设置均提供「跟随浏览器」「简体中文」「English」。访客手动选择只保存在当前浏览器；登录后使用账号保存的偏好，没有账号偏好时跟随浏览器，不套用其他账号或访客的选择。登录后切换会自动保存到当前账号，在其他浏览器登录时恢复；选择「跟随浏览器」以 `PATCH /api/plugins/official.auth/preferences` 的 `{ "language": null }` 清除固定语言。账号选择不会覆盖访客缓存，退出后恢复访客自己的选择。

新注册账号不把注册页面的自动语言写成固定偏好，首次登录继续跟随浏览器。已有账号保存的偏好保留，可通过菜单恢复自动选择。全新 OOBE 仍先确认一次站点语言，之后设置步骤使用所选语言；刷新保留初始化进度。该设置同时决定门户基础内容和邮件的最终回退语言，不覆盖访问者偏好。

切换语言不会重新加载页面、清空表单或重建当前对话。浏览器标签页同步语言缓存；已有账号偏好优先于其他账号的浏览器选择。快速连续切换按顺序保存，退出或切换账号时取消旧账号的待保存项。HTML 的 `lang`、数字与时间格式随当前语言更新。

## 门户多语言内容

在「门户设置」的「内容语言」中切换语言，分别编辑标题、简介、公告、主按钮、文档链接、服务特色、常见问题和公开页面，然后保存并发布。访客切换语言或登录恢复账号偏好时，门户显示对应内容。布局、启用开关、API 地址显示和精选模型共用，不必按语言重复配置。

基础内容使用站点默认语言，其他语言保存在 `portal.translations`；未填写的翻译字段回退基础内容。系统自带的默认标题和按钮有内置中英文版本，自定义内容不自动翻译。关闭门户时，所有语言的草稿都不通过公开接口发布。修改站点默认语言不会翻译原有内容，修改后需核对对应语言的内容。

```json
{
  "portal": {
    "title": "多模型服务",
    "translations": {
      "en-US": {
        "title": "AI model services",
        "primaryLabel": "Browse models",
        "docsUrl": "https://docs.example.com/en",
        "pages": [{ "slug": "help", "title": "Help", "body": "Contact support for help." }]
      }
    }
  }
}
```

同一公开页面建议在各语言使用相同 `slug`，以便保留切换前的页面地址。品牌名称、模型介绍、工单与对话内容保持原文；语言设置不会改写业务数据。

## 插件

公开 UI SDK 提供 `UIHost.i18n`，可获取当前 `locale`、使用 `t` 翻译以及通过 `subscribe` 订阅语言变化。SDK 的 `translateMessage` 支持普通文本插值和缺失词条回退；参数作为文本渲染，不作为 HTML 执行。

```ts
const catalog = {
  "en-US": { "剩余 {count}": "{count} remaining" },
};
const render = () => {
  element.textContent = host.i18n?.t("剩余 {count}", { count: 0 }, catalog)
    ?? "剩余 0";
};
const unsubscribe = host.i18n?.subscribe(render);
render();
// 卸载时调用 unsubscribe?.()。
```

官方插件由共享挂载组件订阅语言变化，复用宿主翻译服务。英文词库仅打包进控制台，插件不重复携带整份词库。新增文案需同时更新英文词条；一致性测试检查界面词条、官方插件名称及插值变量是否齐全。
