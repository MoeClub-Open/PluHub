# 界面语言

首批支持 `zh-CN`（简体中文）和 `en-US`（English）。全新 OOBE 先显示一次中英双语的语言选择，确认后所有设置步骤使用所选单一语言；页面刷新保留选择，已保存的初始化进度继续使用已配置语言。站点默认语言之后可在「品牌与外观」调整，对应控制台插件的 `branding.defaultLanguage`。未配置的旧站点继续使用简体中文。

显示语言按 **账号偏好 → 浏览器缓存 → 站点默认** 解析。语言选择器只显示具体语言，不提供「站点默认」或「跟随站点」选项。访客切换时自动写入浏览器缓存；登录后切换还会自动保存到当前账号，可在账号设置中调整，在新浏览器登录时恢复。站点默认只作为没有账号偏好和浏览器缓存时的回退。

切换语言不会重新加载页面、清空表单或重建当前对话。浏览器标签页同步语言缓存；已有账号偏好优先于其他账号的浏览器选择。快速连续切换按顺序保存，退出或切换账号时取消旧账号的待保存项。HTML 的 `lang`、数字与时间格式随当前语言更新。

系统界面文案与自定义内容分开处理。站点名称、已配置的门户与政策正文、模型介绍、工单和对话内容保持原文；新站点未定制的门户默认文本按默认语言生成。设置默认语言不会翻译已有业务数据。

## 插件

公开 UI SDK 提供 `UIHost.i18n`，可获取当前 `locale`、使用 `t` 翻译以及通过 `subscribe` 订阅语言变化。SDK 的 `translateMessage` 支持普通文本插值和缺失词条回退；参数作为文本渲染，不作为 HTML 执行。

```ts
const catalog = {
  "en-US": { "剩余 {count}": "{count} remaining" },
};
const render = () => {
  element.textContent = host.i18n?.t("剩余 {count}", { count: 0 }, catalog)
    ?? "剩余 0";
};
const unsubscribe = host.i18n?.subscribe(render);
render();
// 卸载时调用 unsubscribe?.()。
```

官方插件由共享挂载组件订阅语言变化，复用宿主翻译服务。英文词库仅打包进控制台，插件不重复携带整份词库。新增文案需同时更新英文词条；一致性测试检查界面词条、官方插件名称及插值变量是否齐全。
