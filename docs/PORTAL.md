# 首次配置与公开门户

全新安装首次访问站点进入 `/#/setup`，顺序为「站点信息 → 公开门户 → 确认设置 → 管理员账号」。站点配置在创建管理员之前保存，创建成功后进入登录页，初始化入口关闭。

设置包含名称、简介、联系邮箱、Logo、主题色、页脚与门户内容。保存的草稿及步骤在重启后保留，管理员密码不保存在浏览器存储。创建账号至少使用 12 字符密码并确认两次输入；前端不得跳过站点确认，后端也拒绝提前创建管理员。

初始化使用专用的 `GET/POST /api/host/setup`。写入要求同源 Origin、自定义请求头和当前修订号，只接受站点表单及初始管理员创建；完整配置和插件管理 API 仍需要管理员认证。创建操作不重置现有账号，不将普通用户提升为管理员，并发只允许一个初始管理员。Users 与 Auth 分别保存用户和密码，通过持久化意图恢复跨插件中断的创建。

已有管理员（包括 CLI 预建账号）的实例不再触发 OOBE，即使旧的 `onboarding.completed` 为 false。已有管理员被禁用也不会重开初始化入口。后台保留独立的品牌与门户设置，不提供重新初始化入口。CLI `bootstrap-admin` 仍用于无人值守部署与本地恢复。

最终检查要求对外 Origin 与当前访问一致，HTTPS 下要求 Auth 的 Secure Cookie 正确。服务器域名切换命令见 [Docker 部署](DOCKER.md)。渠道、模型、计费、注册和验证服务均在创建管理员后进入后台配置，初始化不会自动产生付费请求或发送邮件。

## 门户与公开内容

未登录访客打开根地址时显示门户；`/#/login` 与 `/#/console` 用于登录及控制台。公开页面地址为 `/#/public/<标识>`。管理员从「站点与品牌 → 门户与公开内容」管理：

- 门户开关、首屏标语、标题与简介、站点公告。
- 主按钮文字与链接、文档链接、API 地址及调用示例开关。
- 最多 6 项能力介绍、8 项 FAQ、8 个帮助/政策/说明页面，支持排序和删除。

首页采用居中标题和一个主要操作入口，能力介绍、API 接入与常见问题按顺序展示。API 接入区提供当前站点的 `/v1` 地址及复制操作，调用示例默认折叠，按需展开；关闭 API 接入区后同时隐藏地址和示例。布局适配手机与明暗主题，顶部保留登录或当前账号入口。

页脚默认不展示工程设计理念；没有配置页脚文案或公开链接时隐藏整个页脚。运营者可按需填写版权等面向用户的内容，支持邮箱与政策链接仍可独立展示。

默认品牌文案使用「AI 模型服务」说明用途，不附加口号、服务商标签或重复的能力介绍。首页保留模型入口、API 地址与计费说明；登录标题和说明均为空时只展示居中的登录表单。品牌名称、登录标题、介绍、能力与 FAQ 仍可由运营者自定义。

保存即发布；未保存的编辑留在当前表单。正文以纯文本和换行显示，不执行 HTML、脚本或 iframe。链接限本站路径与 HTTPS，不支持任意嵌入代码。公开页面标识必须唯一，使用小写字母、数字和连字符。

配置保存在 Console `config.portal`，仍使用原有 `http.route` 权限和配置快照更新。公开 `GET /console/public` 仅返回 `branding` 与 `portal`，不包含初始化记录、用户、模型内部绑定、上游凭证或完整配置。关闭门户后该端点不返回所保存的自定义正文；根地址恢复登录/控制台入口。

模型目录插件启用后，访客可在 `/#/models` 浏览平台模型，按关键词、提供商和价格筛选，查看模型介绍、公开模型名、功能、上下文与原价。模型原价以美元 / 百万 Token 展示，实际扣费仍由渠道消耗倍率决定。普通用户可直接选择「开始对话」，开发者接入示例在详情中按需展开；需要使用模型时再登录，登录或注册后保留已选模型。

公开模型接口为 `GET /api/plugins/official.model-catalog/public`，只返回已启用的平台模型和别名，忽略访客传入的渠道及用户参数；不返回上游地址、凭证、内部模型绑定、个人渠道或账户用量。现有 `/models` 渠道目录仍需认证，密钥的模型范围与渠道绑定继续生效。停用目录插件会移除门户模型导航；关闭门户不会关闭模型目录，但首次安装仍先完成初始化。

邮件、支付、注册等能力是否可用仍由对应插件配置决定。帮助及政策正文需要运营者自行编写，不提供虚构的法律条款。
